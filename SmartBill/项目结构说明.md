## 🏗️ 架构说明

### 整体架构
应用采用 **MVVM (Model-View-ViewModel)** 架构模式：

```
┌─────────────────────────────────────────┐
│           UI Layer (View)               │
│  ┌─────────────────────────────────┐   │
│  │      MainActivity               │   │
│  │   (activity_main.xml)           │   │
│  └─────────────┬───────────────────┘   │
│                │                        │
└────────────────┼────────────────────────┘
                 │ observe
                 ▼
┌─────────────────────────────────────────┐
│      ViewModel Layer                    │
│  ┌─────────────────────────────────┐   │
│  │     MainViewModel               │   │
│  │  (LiveData, Coroutines)         │   │
│  └─────────────┬───────────────────┘   │
│                │                        │
└────────────────┼────────────────────────┘
                 │ call
                 ▼
┌─────────────────────────────────────────┐
│      Repository Layer                   │
│  ┌─────────────────────────────────┐   │
│  │   TransactionRepository         │   │
│  └─────────────┬───────────────────┘   │
│                │                        │
└────────────────┼────────────────────────┘
                 │ access
                 ▼
┌─────────────────────────────────────────┐
│      Data Layer (Room)                  │
│  ┌─────────────────────────────────┐   │
│  │   AppDatabase + TransactionDao  │   │
│  │      (SQLite Database)          │   │
│  └─────────────────────────────────┘   │
└─────────────────────────────────────────┘
```

### 数据流

1. **数据采集**：
   ```
   微信/支付宝支付
        ↓
   系统发送通知
        ↓
   PaymentNotificationListener 监听
        ↓
   PaymentParser 解析
        ↓
   存入数据库
   ```

2. **数据展示**：
   ```
   用户打开应用
        ↓
   MainActivity 启动
        ↓
   MainViewModel 查询数据
        ↓
   TransactionRepository 获取
        ↓
   LiveData 通知UI更新
        ↓
   RecyclerView 显示列表
   ```

## 🔑 核心组件说明

### 1. PaymentNotificationListener (通知监听服务)

**作用**：监听系统通知栏，捕获支付类通知

**工作原理**：
- 继承自 `NotificationListenerService`
- 需要用户授予"通知使用权"
- 在 `onNotificationPosted()` 中接收所有通知
- 过滤出支付相关应用的通知
- 提取通知内容并解析

**支持的应用包名**：
- `com.tencent.mm` - 微信
- `com.eg.android.AlipayGphone` - 支付宝
- 各大银行App

### 2. SmsReceiver (短信接收器)

**作用**：监听短信，捕获银行扣款通知

**工作原理**：
- 继承自 `BroadcastReceiver`
- 监听 `SMS_RECEIVED_ACTION`
- 识别包含"支出"、"消费"等关键词的短信
- 解析金额和商户信息

### 3. PaymentParser (支付解析器)

**作用**：从文本中提取支付信息

**解析内容**：
- 金额（正则：`¥?(\d+\.?\d*)`）
- 商家名称
- 应用识别
- 分类判断

**解析规则示例**：
```kotlin
// 微信支付
"微信支付 向美团收款方付款¥28.50"
→ 金额: 28.50, 应用: 美团, 支付方式: 微信支付

// 支付宝
"你向淘宝付款¥199.00元"
→ 金额: 199.00, 应用: 淘宝, 支付方式: 支付宝

// 银行短信
"您尾号1234的卡消费50.00元，商户：美团"
→ 金额: 50.00, 商户: 美团, 支付方式: 银行卡
```

### 4. Room 数据库

**数据表结构**：
```sql
CREATE TABLE transactions (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    amount REAL NOT NULL,           -- 金额
    appName TEXT NOT NULL,          -- 应用名称
    paymentMethod TEXT NOT NULL,    -- 支付方式
    merchantName TEXT,              -- 商家名称
    timestamp INTEGER NOT NULL,     -- 时间戳
    source TEXT NOT NULL,           -- 来源(notification/sms)
    rawText TEXT,                   -- 原始文本
    category TEXT                   -- 分类
);
```

## 🔐 权限说明

### 1. 通知监听权限
```xml
<service android:permission="android.permission.BIND_NOTIFICATION_LISTENER_SERVICE">
```
- **用途**：监听微信、支付宝等支付通知
- **敏感级别**：高
- **需要用户操作**：必须在系统设置中手动开启

### 2. 短信权限
```xml
<uses-permission android:name="android.permission.RECEIVE_SMS" />
<uses-permission android:name="android.permission.READ_SMS" />
```
- **用途**：接收和读取银行扣款短信
- **敏感级别**：高
- **运行时申请**：Android 6.0+ 需要动态申请

## 🔧 关键技术点

1. **Kotlin Coroutines**：异步数据库操作
2. **Room Database**：本地数据持久化
3. **LiveData**：响应式数据更新
4. **ViewBinding**：类型安全的视图绑定
5. **NotificationListenerService**：系统通知监听
6. **BroadcastReceiver**：系统广播接收
