# SmartBill - 智能记账助手

## 📱 应用简介

SmartBill是一款全自动记账Android应用，能够自动监听微信支付、支付宝、银行卡等支付通知和短信，智能提取消费信息并按应用分类统计，让你清楚掌握每个App的消费情况。

### ✨ 核心功能

- ✅ **全自动记账**：无需手动输入，自动捕获支付信息
- 📊 **按应用统计**：清晰展示在每个App上花了多少钱
- 🔔 **通知监听**：监听微信、支付宝、银行App的支付通知
- 📱 **短信解析**：自动解析银行卡扣款短信
- 🔒 **隐私安全**：所有数据仅存储在本地，不联网不上传
- 📈 **消费统计**：今日/本周/本月消费一目了然

### 支持的支付方式

- 微信支付
- 支付宝
- 各大银行卡（通过短信和App通知）
- 云闪付

## 🛠️ 编译安装

### 前置要求

1. **安装 Android Studio**
   - 下载地址：https://developer.android.com/studio
   - 版本要求：Android Studio Hedgehog (2023.1.1) 或更高

2. **安装 JDK**
   - 版本要求：JDK 17 或更高
   - Android Studio通常会自动安装

### 编译步骤

#### 方法一：使用Android Studio（推荐）

1. 打开Android Studio
2. 选择 `File` → `Open`，选择SmartBill文件夹
3. 等待Gradle同步完成（首次可能需要下载依赖，需要几分钟）
4. 点击 `Build` → `Build Bundle(s) / APK(s)` → `Build APK(s)`
5. 构建完成后，点击通知栏的 `locate` 查看APK位置
6. APK文件位于：`app/build/outputs/apk/debug/app-debug.apk`

#### 方法二：使用命令行

**Windows系统：**
```bash
# 在SmartBill目录下打开命令行，运行：
build.bat
```

**Linux/Mac系统：**
```bash
# 在SmartBill目录下打开终端，运行：
chmod +x build.sh
./build.sh
```

**手动命令：**
```bash
# Windows
gradlew.bat clean assembleDebug

# Linux/Mac
./gradlew clean assembleDebug
```

### 安装到手机

1. 将生成的 `app-debug.apk` 文件传输到手机
2. 在手机上打开APK文件
3. 允许"安装未知来源应用"的权限
4. 点击安装

## 📖 使用指南

### 首次使用

1. **安装并打开应用**
   - 首次打开会看到权限请求提示

2. **开启通知监听权限**
   - 应用会引导你进入系统设置
   - 找到"SmartBill"或"智能记账"
   - 开启通知访问权限
   - 这是核心功能，必须开启

3. **开启短信读取权限**
   - 用于监听银行卡扣款短信
   - 在权限请求对话框点击"允许"

4. **完成设置**
   - 所有权限开启后，应用会自动开始工作
   - 无需任何手动操作

### 日常使用

应用会在后台自动工作，你只需：

1. **正常使用微信、支付宝等支付**
   - 支付成功后，应用自动记录
   - 通常在几秒内就能在记录列表看到

2. **查看统计**
   - 打开应用即可查看今日/本周/本月消费
   - 自动按应用分类统计

3. **管理记录**
   - 长按记录可以删除
   - 点击右上角设置可以清空所有数据

### 常见问题

**Q: 为什么有些支付没有被记录？**
A: 可能原因：
- 通知监听权限未开启或被系统回收
- 该应用的通知被关闭
- 该应用的支付通知格式不在识别范围内
- 解决方法：重新检查权限，确保应用未被系统清理

**Q: 能记录哪些应用的消费？**
A: 理论上能记录所有通过微信、支付宝、银行卡支付的消费。具体包括：
- 美团、淘宝、京东、拼多多等电商
- 滴滴出行等出行类
- 爱奇艺、腾讯视频、哔哩哔哩等视频类
- 其他所有使用上述支付方式的消费

**Q: 数据安全吗？**
A: 完全安全！
- 所有数据仅存储在手机本地SQLite数据库
- 应用不申请网络权限，无法上传数据
- 不连接任何服务器
- 你可以随时清空数据

**Q: 会耗电吗？**
A: 耗电极低：
- 采用被动监听机制，不主动轮询
- 仅在收到通知/短信时工作几毫秒
- 后台无常驻进程

**Q: 为什么需要短信权限？**
A: 用于读取银行卡扣款短信，如果你不需要记录银行卡消费，可以不授予此权限。

**Q: 如何备份数据？**
A: 当前版本数据存储在应用私有目录，建议：
- 定期截图保存统计数据
- 后续版本会添加导出功能

## 🔧 进阶设置

### 省电优化

部分手机系统会限制后台应用，导致通知监听失效。请进行以下设置：

1. **关闭电池优化**
   - 设置 → 电池 → 省电模式/电池优化
   - 找到"SmartBill"，设置为"不优化"

2. **允许自启动**
   - 设置 → 应用管理 → SmartBill → 自启动
   - 开启"允许自启动"

3. **锁定后台**
   - 在最近任务中锁定SmartBill
   - 防止被系统清理

### 通知设置

如果某些应用的支付通知没有被记录：

1. 检查该应用的通知权限是否开启
2. 检查该应用是否发送了支付成功通知
3. 微信需要在"设置→新消息提醒"中开启"收付款到账通知"

## 📋 支持的银行（通过短信）

应用会自动识别以下关键词的短信：
- 支出、消费、交易、扣款、支付、付款、刷卡

几乎所有银行的扣款短信都会被正确识别。
