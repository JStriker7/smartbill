# SmartBill 快速开始指南

## 🚀 5分钟上手指南

### 第一步：编译APK

**如果你有Android Studio：**
1. 打开Android Studio
2. File → Open → 选择SmartBill文件夹
3. 等待Gradle同步（第一次需要几分钟下载依赖）
4. Build → Build Bundle(s) / APK(s) → Build APK(s)
5. 完成后在 `app/build/outputs/apk/debug/` 找到 `app-debug.apk`

**如果你没有Android Studio：**
1. 下载并安装 Android Studio（推荐）
   - 官网：https://developer.android.com/studio
   - 安装后会自动配置好Java环境
2. 按照上面的步骤操作

### 第二步：安装到手机

1. 将 `app-debug.apk` 传到手机（微信/QQ/USB都可以）
2. 在手机上点击APK文件
3. 允许"安装未知来源应用"
4. 点击安装

### 第三步：配置权限

**重要！这是核心功能，必须设置：**

1. **开启通知监听权限**
   ```
   打开应用 → 会提示需要通知监听权限
   → 点击"去开启" → 找到"SmartBill"或"智能记账"
   → 打开开关
   ```

2. **开启短信读取权限**
   ```
   会弹出权限请求 → 点击"允许"
   ```

3. **关闭电池优化（重要！）**
   ```
   设置 → 电池 → 电池优化/省电模式
   → 找到SmartBill → 设置为"不优化"
   ```

### 第四步：测试一下

1. 微信或支付宝随便买点东西（比如充个话费）
2. 支付成功后，打开SmartBill
3. 你应该能看到刚才的消费记录！

## ⚠️ 常见问题

### 问题1：编译时报错

**错误：Gradle sync failed**
- 原因：网络问题，无法下载依赖
- 解决：使用科学上网工具，或者等待重试

**错误：SDK not found**
- 原因：Android SDK未安装
- 解决：Android Studio会自动提示下载，点击确认即可

### 问题2：有些支付没被记录

**检查清单：**
- [ ] 通知监听权限已开启？
- [ ] 应用未被清理或强制停止？
- [ ] 微信/支付宝的通知权限已开启？
- [ ] 手机电池优化已关闭？

**微信支付记录方法：**
```
微信 → 我 → 设置 → 新消息提醒
→ 开启"收付款到账通知"
```

### 问题3：后台被杀死

不同手机品牌处理方式：

**小米/红米：**
```
设置 → 应用设置 → 应用管理 → SmartBill
→ 省电策略：无限制
→ 自启动：允许
→ 后台弹出界面：允许
```

**华为/荣耀：**
```
设置 → 应用 → 应用启动管理 → SmartBill
→ 关闭"自动管理"
→ 全部设为允许
```

**OPPO/一加：**
```
设置 → 电池 → 应用耗电管理 → SmartBill
→ 允许后台运行
```

**vivo：**
```
i管家 → 应用管理 → 权限管理 → SmartBill
→ 自启动：允许
→ 后台高耗电：允许
```

## 📊 功能说明

### 自动识别的支付类型

✅ **微信支付**
- 扫码支付
- 转账
- 红包（收付款通知）

✅ **支付宝**
- 扫码支付  
- 转账
- 收款

✅ **银行卡（通过短信）**
- 所有银行的扣款短信
- 自动提取金额和商户

### 自动识别的应用

系统会自动识别以下常见应用：
- 🍔 外卖：美团、饿了么
- 🛒 电商：淘宝、天猫、京东、拼多多
- 🚗 出行：滴滴出行
- 📺 视频：爱奇艺、腾讯视频、哔哩哔哩、优酷
- 🎵 音乐：网易云音乐、QQ音乐
- 🎬 娱乐：抖音、快手

其他应用会显示商家名称。

## 💡 使用技巧

### 技巧1：查看详细记录
长按任意消费记录可以删除（误记录或测试数据）

### 技巧2：定期检查权限
建议每周打开应用看一下，确保后台服务正常运行

### 技巧3：统计分析
- 看"今日"了解每天花了多少
- 看"本周"控制周消费
- 看"本月"月底不吃土

### 技巧4：隐私保护
- 数据完全本地存储
- 不联网、不上传
- 可随时在设置中清空所有数据
